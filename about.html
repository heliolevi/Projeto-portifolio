Where engineering meets real impact.

I'm Hélio Levi, 18 years old, a Software Engineering student (3rd semester). I build the infrastructure institutions run on — REST APIs, cloud systems and data pipelines engineered with TypeScript, NestJS, Next.js, AWS and PostgreSQL. But the code is never the point. The point is what it makes possible.

I got into engineering because I kept seeing the same gap: organizations with real potential, running on systems that were slow, opaque, or impossible to trust. That gap is where I work. I design back-end architecture the way a strategist designs a plan — for accuracy, for scale, and for accountability, because a system nobody can audit is a system nobody should rely on.

That's the lens I bring to public administration and political mandates in Maranhão: technology isn't a support function for governance, it's the infrastructure governance runs on. I don't sell code — I build the layer that makes decisions faster, data trustworthy, and operations lean enough to actually scale.
