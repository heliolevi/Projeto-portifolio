Event gamification LIVE · SEP 30 – OCT 2

IT-WORKS · QR Hunt

A game that turns a three-day tech event into a hunt.

itworks-undb.vercel.app
GamificationQR CodeAuthWeb app
Open live project

The context

IT-WORKS is the technology event at Escola de Tecnologia UNDB, held on September 30 and October 1–2. Events like this compete for attention across several days and many spaces — and attendance alone doesn't tell people where to go next.

What I built

A web game for the event: attendees create an account, sign in and take part in a QR-code hunt. The interface follows the event's identity — a pixel-art planet, wide display type and a dark, neon-lit palette — so the game feels like part of IT-WORKS, not an add-on.

Why it matters

Gamification gives a reason to explore: every code is a small objective, and the sign-in turns anonymous foot traffic into players. It's a compact example of how I approach product work — a clear goal, a working system, and a real audience using it while it's live.

São Luís Weather Watch

Real-time, auditable weather data for a city that needs to act on it.

The problem

Civil Defense and municipal decision-makers in São Luís often act on weather information that's outdated, unverified, or scattered across sources — a real risk in a region exposed to heavy rain, flooding, and heat events. When the data behind an emergency decision can't be verified, public trust erodes with it.

The stack and why

Node.js + Express power a fast, reliable API layer that ingests and serves meteorological data without bottlenecks. MongoDB handles the high-frequency, semi-structured readings from a live weather API integration — a single source of truth instead of manual entry. Every endpoint is documented with Swagger, so the API itself becomes an audit trail, not a black box. Even PNPM was a deliberate choice: optimizing dependency management the same way I optimize every other layer.

The strategic value

A working proof of concept for public bodies: how a Civil Defense unit, a city hall, or a political mandate can base real decisions on real-time, auditable data instead of assumption. It shows what data-driven governance looks like in practice — transparent sourcing, documented APIs, and infrastructure built to be trusted.

The problem

Teams — from small businesses to political offices — lose hours every week to repetitive manual work: scheduling, follow-ups, status tracking, routine communication. That time isn't just a cost, it's capacity a lean team can't afford to lose.

The stack and why

Java + Spring Boot — the market standard for enterprise-grade robustness and security — a deliberate choice for a tool meant to run unattended in the background of an operation, not a quick script. It's deployed on Google Cloud for the stability, high availability, and enterprise-level security that automation touching real workflows requires.

The strategic value

Bot Task proves a simple point with real code: operational efficiency is an engineering outcome, not a slogan. For a political mandate or a lean public office, automation like this is the difference between staff spending time on strategy versus repetitive administrative work.
