Public Sector Proof of Concept

São Luís Weather Watch

Real-time, auditable weather data for a city that needs to act on it

The Problem

Civil Defense and municipal decision-makers in São Luís often act on weather information that's outdated, unverified, or scattered across sources — a real risk in a region exposed to heavy rain, flooding, and heat events. When the data behind an emergency decision can't be verified, public trust erodes with it.

The Stack & Why

Node.js + Express power a fast, reliable API layer that ingests and serves meteorological data without bottlenecks. MongoDB handles the high-frequency, semi-structured readings coming from a live weather API integration — a single source of truth instead of manual entry. Every endpoint is documented with Swagger, so the API itself becomes an audit trail, not a black box. Even PNPM was a deliberate choice — optimizing dependency management the same way I optimize every other layer.

The Strategic Value

This is a working proof of concept for public bodies: how a Civil Defense unit, a city hall, or a political mandate can base real decisions on real-time, auditable data instead of assumption. It shows what data-driven governance looks like in practice — transparent sourcing, documented APIs, and infrastructure built to be trusted.

Node.js • Express • MongoDB • Swagger • Weather API Integration

Operational Efficiency Proof of Concept

Bot Task

Automation built to run reliably inside a real operation, not a demo

The Problem

Teams — from small businesses to political offices — lose hours every week to repetitive manual work: scheduling, follow-ups, status tracking, routine communication. That time isn't just a cost, it's capacity a lean team can't afford to lose.

The Stack & Why

Java + Spring Boot — the market standard for enterprise-grade robustness and security — a deliberate choice for a tool meant to run unattended in the background of an operation, not a quick script. It's deployed on Google Cloud for the stability, high availability, and enterprise-level security that automation touching real workflows requires.

The Strategic Value

Bot Task proves a simple point with real code: operational efficiency is an engineering outcome, not a slogan. For a political mandate or a lean public office, automation like this is the difference between staff spending time on strategy versus spending it on repetitive administrative work — a direct, measurable productivity gain.
